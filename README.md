# FUMURA — Luxury Perfume Website
fumura-homepage.png

## About The Project

FUMURA is a fictional luxury perfume brand website created as an AI-powered portfolio project.

This project explores how AI tools can be used for branding, website ideation, and creating digital experiences.

## Creation Process

The project was created using AI tools and my creative direction.

The process included:

- Developing the FUMURA brand concept
- Creating the luxury design direction
- Planning website sections and features
- Writing detailed prompts using ChatGPT
- Using Google AI Studio to generate the website
- Exporting the generated project
- Deploying the website using Vercel

## My Contribution

My role included:

- Brand concept and creative direction
- Prompt creation and refinement
- Planning website requirements
- Reviewing AI-generated results
- Deploying the final website

## AI Transparency

This project was created using AI-generated code based on my instructions and prompts.

It is not presented as a fully hand-coded website. The purpose of this project is to demonstrate AI tool usage, prompt engineering, and creating digital prototypes.

## Tools Used

- ChatGPT
- Google AI Studio
- Vercel
- Prompt Engineering
